# 長度小探險

給國小三年級使用的長度學習遊戲。公尺、公分、毫米皆以整數及複合單位表示。

- 拖動尺、調整物品長度。
- 換算複合單位，例如 5 公尺 3 公分 = 503 公分 = 5030 毫米。
- 練習提示、星星獎勵。
- 10 題測驗、計分與錯題解說。

## GitHub Pages 發布

1. 建立名為 `length-explorer` 的公開儲存庫。
2. 將 `index.html`、`.nojekyll` 與本檔案放在 `main` 分支的根目錄。
3. 開啟儲存庫的 **Settings → Pages**。
4. Source 選 **Deploy from a branch**，分支選 **main**、資料夾選 **/(root)**，按 **Save**。
5. 等待 GitHub Pages 完成發布，以 Pages 設定頁顯示的網址為準。

此專案不需要安裝套件或執行建置。也可以直接用瀏覽器開啟 `index.html`。

## 紀錄與尺寸

星星與最近五次測驗紀錄儲存在使用者的瀏覽器，不會傳送到伺服器。
尺用來理解長度比例，並不是螢幕上的實際尺寸。
